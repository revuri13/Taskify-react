# Taskify

Taskify is a simple task management application built with React and JavaScript. I created this project to practice React concepts while building a clean and easy-to-use productivity dashboard.

## Features

- Add new tasks
- View and organize tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks
- Task statistics dashboard
- Light and dark theme
- Responsive layout

## Built With

- React
- JavaScript
- HTML
- CSS

## What I Learned

While building Taskify, I practiced working with React components, state, event handling, and organizing a React application into reusable components.

I also focused on creating a clean interface that works well across different screen sizes.
